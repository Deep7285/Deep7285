## Some Ongoing and Recent Projects

**🔬 Nano-porosity detection in TEM images using computer Vision Approach** 
Collaborated with [Rajat Nama](https://nanoanalysis.web.ox.ac.uk/people/rajat-nama) to develop and publish **PoroDet**: an **Open-Source Python package** for segmenting nano-porosities in Fresnel-contrast TEM images of Zr-alloy, designed to train on limited datasets using a U-Net CNN architecture.  
→ [`PoroDet`](https://github.com/Deep7285/PoroDet) · [![DOI](https://zenodo.org/badge/1095762451.svg)](https://doi.org/10.5281/zenodo.19342741)

**🧮 Physics-Informed Surrogate Modelling of Friction Stir Welding** 
The project focuses on physics-based modelling using experimental data and existing physical relationships to explore additional process parameters for improved properties, using a GPR surrogate model and Bayesian optimisation for the FSW process–property design space. 
→ [Physics-Informed Surrogate Modelling for FSW](https://github.com/Deep7285/Physics-Informed-Surrogate-Modelling-for-Dissimilar-FSW)

**🔭 Extreme Events forecasting using physics-aware ML/DL modelling**  
Working with high-dimensional data to detect and forecast extreme events using physics-aware ML/DL approaches. 
→ [`Climate-code-files`](https://github.com/Deep7285/Climate-code-files)

**🤝 Human response matching app**
